PL:

Najpierw wprowadzamy nazwę pliku msh.
Wybieramy opcje obrotu modelu czyli wprowadzamy "y".
Wybieramy oś x czyli wprowadzamy "x"
Wartość obrotu:
Jedna jednostka obrotu czyli 1 oznacza po prostu 1 * (pi/2) czyli to będzie 90 stopni.
Można wprowadzić nawet ułamek np 0.5 czyli to będzie oznaczało 0.5 * (pi/2) czyli to będzie pi/4 czyli 45 stopni.

ZALECAM UŻYĆ WARTOŚCI -1 w przypadku osi obrotu x ponieważ to spowoduje, że model będzie stał pionowo tak jak powinien.

No i zalecam na koniec użycie int czyli wprowadzamy "n".
Gotowe!

***********************************************************************
Program nie obsługuje particlesów ale potrafi je wykryć i je ominąć.
Do exportu wszystkiego zaleca się użycie po prostu pliku .bat "Export_all.bat".
***********************************************************************

Eng:

First, enter the name of the msh file.
Select the model rotation options, i.e., enter "y".
Select the x-axis, i.e., enter "x".
Rotation value:
One rotation unit, i.e., 1, simply means 1 * (pi/2), which is 90 degrees.
You can even enter a fraction, e.g., 0.5, which means 0.5 * (pi/2), which is pi/4, or 45 degrees.

I RECOMMEND USING THE VALUE -1 for the x-axis rotation because this will cause the model to stand upright as it should.

And finally, I recommend using int, i.e., entering "n".
Done!

***********************************************************************
-> The program does not support particles, but it can detect and bypass them.
-> To export everything, it is recommended to simply use the .bat file "Export_all.bat".
***********************************************************************
